# BELONG Lab website

Ready for GitHub Pages. No installation or build command required.

## Publish
1. Upload the CONTENTS of this folder, including assets/, to the root of eunbeakim/belong-lab. Do not upload the ZIP itself or an enclosing folder.
2. Settings > Pages > Source: Deploy from a branch.
3. Branch: main. Folder: /(root). Save.
4. Check the Actions tab for the Pages deployment to finish.
5. Open https://eunbeakim.github.io/belong-lab/

## Edit
- index.html: Home
- people.html: People
- extension.html: Extension
- research.html: Research, publications, presentations
- resources.html: Resources
- lab-update.html: Lab Updates
- assets/typography.css: Shared typography
- assets/: Images and logos

Edit a file in GitHub, then commit changes. GitHub Pages republishes changes from the configured branch.

ChatGPT Sites and GitHub Pages are separate copies. Changes to one do not automatically update the other.
